## How it works

`main.py` (Python 3, stdlib only) writes the single word to `entry.txt` in the output directory — `/output` by default, or `$ENTRY_OUTPUT_DIR` when set. No randomness, no input, no network: two runs produce byte-identical output.

```sh
python3 main.py
```

The word is 10 characters, inside the competition's 1–30 character gate.
